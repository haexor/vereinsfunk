# Data Model: Berechtigungsbasierte Navigation

Keine Datenmodelländerungen. Die Funktion verwendet bestehende Rollen und Berechtigungen.

- `organization.manage`: bestehende Berechtigung für vereinsweite Verwaltung.
- `member.invite`, `member.remove`: bestehende scopespezifische Rechte; allein nicht hinreichend, um den vereinsweiten Mitgliederlink zu zeigen.
